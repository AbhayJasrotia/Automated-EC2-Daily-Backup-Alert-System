Today I improved the Lambda backup function.

## Improvements

The Lambda function now:

- Creates EBS snapshots
- Adds tags to snapshots
- Writes useful logs to CloudWatch
- Sends a success notification through SNS
- Sends a failure notification if the backup fails

## Snapshot tags

- Name: EC2-Daily-Backup
- BackupType: Automated
- Source: backup-demo-server
- CreatedBy: Lambda

## Failure testing

I temporarily used an invalid EC2 instance ID to test the failure path.

The Lambda function failed as expected and sent a failure notification through SNS.

I then restored the correct instance ID and confirmed that the backup worked again.

## Current architecture

EventBridge
     ↓
   Lambda
     ↓
    EBS
     ↓
  Snapshot
     ↓
    SNS
     ↓
  Email
