Snapshot Retention & Cleanup
I added snapshot retention and cleanup to the backup system.

## What I learned

- Backups should not grow forever.
- EBS snapshots can be automatically deleted based on age.
- Lambda can manage the snapshot lifecycle using the EC2 API.
- Environment variables can be used to configure retention.
- I used tags to identify snapshots created by my backup system.
- Lambda now has permission to delete old backup snapshots.

## Retention

Retention period:

7 days

Environment variable:

RETENTION_DAYS=7

## Snapshot tags

Name = EC2-Daily-Backup
BackupType = Automated
Source = backup-demo-server
CreatedBy = Lambda

## Backup process

EventBridge Scheduler
        ↓
      Lambda
        ↓
Create EBS Snapshot
        ↓
   Tag Snapshot
        ↓
Find Old Backups
        ↓
Delete Old Backups
        ↓
       SNS
        ↓
      Email

## Testing

I tested the Lambda manually and verified:

- New snapshot was created.
- Snapshot tags were applied.
- Cleanup process ran.
- CloudWatch logs recorded the process.
- SNS sent the backup result.

## Goal

Prevent old backup snapshots from accumulating indefinitely while keeping recent backups available for recovery.
