# Day 4 — IAM Role for Lambda

Today I created the IAM permissions that my Lambda function will use.

## What I learned

An IAM role allows an AWS service such as Lambda to obtain temporary permissions without using hard-coded AWS credentials.

I created:

- `EC2BackupLambdaRole`
- `EC2BackupLambdaPolicy`

I also attached:

- `AWSLambdaBasicExecutionRole`

## Permissions

The custom policy allows Lambda to:

- Create EBS snapshots
- Describe EC2 instances
- Describe EBS volumes
- Describe snapshots
- Create tags
- Publish messages to SNS

The Lambda role will later be used by the backup function.

## Architecture

Lambda
 ↓
EC2BackupLambdaRole
 ↓
EC2BackupLambdaPolicy
 ├── EBS snapshot permissions
 └── SNS publish permission

Lambda
 ↓
AWSLambdaBasicExecutionRole
 ↓
CloudWatch Logs
