AWS Lambda Backup Function

Today I created the Lambda function that performs the actual EC2 backup.

## What I built

- Created `ec2-daily-backup`
- Used Python and Boto3
- Connected Lambda to EC2
- Found the EBS volume attached to the EC2 instance
- Created an EBS snapshot
- Published a backup status message to SNS
- Received the notification by email

## IAM

Lambda uses:

`EC2BackupLambdaRole`

No AWS access keys are stored in the code.

## Flow

Lambda
 ↓
EC2 API
 ↓
Find EBS volume
 ↓
Create snapshot
 ↓
SNS
 ↓
Email

## Test result

The Lambda function was manually triggered and successfully created an EBS snapshot and sent a notification.
