# Day 9 — IAM Least Privilege

Today I improved the IAM security of my backup system.

## What I changed

I reviewed the permissions used by the Lambda execution role.

Role:

EC2BackupLambdaRole

The Lambda needs permission to:

- Describe EC2 instances
- Find EBS volumes
- Create EBS snapshots
- Tag snapshots
- Delete old backup snapshots
- Publish backup notifications
- Write CloudWatch logs

## SNS security improvement

Previously SNS publish permission used:

Resource = *

I changed this so the Lambda can publish specifically to my BackupAlerts SNS topic.

## IAM structure

EC2BackupLambdaRole
    ↓
AWSLambdaBasicExecutionRole
    ↓
CloudWatch Logs

EC2BackupLambdaPolicy
    ↓
EC2 backup operations
    ↓
BackupAlerts SNS topic

## Testing

After changing the IAM policy I ran the Lambda again.

The backup succeeded and the SNS notification was received.

## What I learned

IAM roles should only provide the permissions required by an application.

Giving an application unnecessary permissions increases the possible impact if the application or credentials are compromised.
