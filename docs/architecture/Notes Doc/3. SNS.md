# Day 3 — Amazon SNS

Today I set up Amazon SNS for the backup notification system.

## What I learned

- SNS stands for Simple Notification Service.
- An SNS Topic acts as a notification channel.
- A subscription tells SNS where to send notifications.
- I created a topic called `BackupAlerts`.
- I subscribed my email address to the topic.
- I confirmed the email subscription.
- I published a test message and received it by email.
